# Repository instructions

- Before starting project work, read `MTE252_Project01.pdf` in the repository root and follow its project requirements.
- Follow the repository's existing naming conventions. Match the surrounding MATLAB code and filenames; audio inputs use lowercase `<type>_<topic>.mp3` with underscores between words, as documented in `Project_Files/README.md`. Preserve existing names unless the task requires a rename.
- After every completed change, run the relevant checks, commit the task's files, and push the commit to the current branch's remote. Use concise, imperative commit messages consistent with the existing history. Leave unrelated user changes untouched. If a push fails, report the failure and what remains to be pushed.
